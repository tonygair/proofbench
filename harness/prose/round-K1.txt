1. AN "out" PARAMETER MUST BE INITIALISED ON EVERY PATH, AND FLOW ANALYSIS
   WILL NOT TAKE A LOOP'S WORD FOR IT.

   A loop that plainly writes every element of an "out" array still leaves flow
   analysis saying the array "might not be initialized".

   object at once:
